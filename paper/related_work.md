# 2. Related Work

## Contextual biasing during decoding

Contextual biasing supplies an ASR system with vocabulary that is relevant to its current application or interaction. Deep Context introduced Contextual Listen, Attend and Spell (CLAS), which learns representations of contextual phrases jointly with an end-to-end recognizer and accepts a phrase list at inference time. This establishes that contextual phrases can affect recognition through learned internal representations, rather than only through transcript editing. ([Pundak et al., 2018](https://arxiv.org/abs/1808.02480)) Shallow-fusion contextual biasing instead incorporates contextual language-model scores during decoding; its treatment of subword units addresses the problem that a rare-word hypothesis can be discarded before a whole-word reward becomes available. ([Zhao et al., 2019](https://www.isca-archive.org/interspeech_2019/zhao19d_interspeech.html)) The tree-constrained pointer generator (TCPGen) connects a prefix tree built from a biasing list to a neural output distribution, allowing the model to select contextually relevant wordpieces. ([Sun et al., 2021](https://arxiv.org/abs/2109.00627))

ECHO builds on the same principle of changing lexical preferences during decoding. Its current prefix-conditioned logit processor is a lightweight inference heuristic, not a replacement for learned contextual attention, trie-constrained generation, or search over competing hypotheses. The distinction pursued here is how the biasing vocabulary is obtained: a later call receives entries interpreted from the user's earlier spoken explanations. Accordingly, improvements in vocabulary acquisition and improvements in the biasing algorithm must be evaluated separately.

## Generative correction of ASR hypotheses

Large language models can also improve recognition after an initial transcript has been produced. HyPoradise studies generative error correction from N-best hypotheses, including generation of a transcription beyond selecting an existing candidate. ([Chen et al., 2023](https://proceedings.neurips.cc/paper_files/paper/2023/hash/6492267465a7ac507be1f9fd1174e78d-Abstract-Datasets_and_Benchmarks.html)) Whispering LLaMA incorporates acoustic information and linguistic representations into generative correction, highlighting that a text hypothesis need not be the corrector's only source of evidence. ([Radhakrishnan et al., 2023](https://aclanthology.org/2023.emnlp-main.618/)) For Chinese ASR, ChineseHP and Pinyin regularization explicitly examine hypothesis correction and the usefulness of pronunciation information in LLM prompts. ([Tang et al., 2024](https://www.isca-archive.org/interspeech_2024/tang24_interspeech.html))

ECHO shares the use of linguistic inference over imperfect hypotheses, but the immediate product of its LLM is a small set of reusable lexical entries rather than a rewritten transcript. An explanation can constrain a name's spelling even when its first transcription is wrong; it can also be corrupted itself. The proposed loop therefore asks the model to interpret the explanation while preserving unaffected name characters. The resulting entry influences subsequent acoustic decoding. This does not remove the need for acoustic verification, nor does a quoted evidence span establish that the inferred spelling is correct.

## Retrieved vocabulary and conversational context

Retrieval-based systems address the cost and interference associated with large contextual inventories. RECAST learns to retrieve keywords using pretrained ASR decoder states, then provides the selected terms to a downstream speech language model. ([Mittal et al., 2025](https://aclanthology.org/2025.findings-emnlp.203/)) Conversation history and lexical lists can also be combined: multilevel contextual prompting places both sources in a unified Speech LLM prompt and uses phonetic filtering to select relevant hotwords. ([Zheng et al., 2026](https://doi.org/10.1016/j.specom.2026.103458)) ECHO consequently does not claim that incorporating history or combining it with hotwords is new. It focuses on converting an explanation into an entry when the desired spelling is not already available as a reliable item in a supplied list. Retrieval and filtering remain complementary options if this accumulated memory grows.

## Reusing corrections and managing unreliable memory

Remembering user corrections predates ECHO. Audio-exemplar correction stores an utterance together with an associated text correction and compares later audio against those exemplars to repair recognition output. ([Pundak et al., 2022](https://www.isca-archive.org/interspeech_2022/pundak22_interspeech.html)) More recently, an ontology-memory framework organizes conversational entities, terminology, variants, and relations into updatable evidence for correcting later ASR hypotheses. ([Li et al., 2026](https://arxiv.org/abs/2606.13464)) These are close precedents for retaining interaction-derived knowledge. ECHO examines a narrower route: interpreting noisy spoken spelling explanations into lexical memory and applying that memory while decoding later utterances, rather than matching stored audio or using an ontology to rewrite an already completed hypothesis.

Such memory must remain fallible. Work on contextual exposure bias explicitly studies the mismatch between reliable training histories and erroneous inference histories. ([Guo et al., 2026](https://arxiv.org/abs/2603.24034)) Context-steered reasoning for hotword-aware recognition likewise treats candidate relevance as a decision to ground in audio, rather than assuming every supplied candidate should appear. ([Wang et al., 2026](https://arxiv.org/abs/2610.26986)) These findings motivate evaluating both the benefit of a correct explanation and the harm from an incorrect or ambiguous one. ECHO's present prototype makes memory entries and token-level changes inspectable, but it does not yet establish calibrated confidence, automatic conflict resolution, or robustness to misleading explanations. Its proposed contribution is therefore the explanation-to-memory-to-decoding interaction, whose value must be tested against existing correction, memory, and contextual-biasing alternatives.
