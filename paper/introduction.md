# 1. Introduction

Recognizing a name correctly once is useful; retaining a user's explanation of that name can make subsequent interactions more reliable. Consider a speaker who introduces a person and then explains which characters form the name. The explanation supplies information that pronunciation alone may not distinguish, yet a recognizer can transcribe the explanation incorrectly as well as the name. A system that merely stores the observed spelling risks preserving the original error. The challenge is therefore to interpret the explanation, recover the lexical information it supports, and make that information available when the name occurs again.

Contextual automatic speech recognition (ASR) addresses related difficulties by incorporating phrases that are relevant to the current interaction. Neural contextualization and contextual decoding can guide recognition toward supplied names and terms, as illustrated by Contextual Listen, Attend and Spell (CLAS). These methods establish the value of a vocabulary tailored to the interaction. They also motivate a complementary question: how can an application construct that vocabulary when the useful evidence arrives as an informal spoken explanation rather than a verified list? [Pundak et al., 2018](https://arxiv.org/abs/1808.02480); [Zhao et al., 2019](https://www.isca-archive.org/interspeech_2019/zhao19d_interspeech.html).

This question is particularly concrete for Mandarin names containing homophones. Suppose an ASR system produces “我叫鱼明洞，鱼是年年有鱼的鱼” (“My name is Yu Mingdong; Yu is the character in niannian youyu”). If the speaker intends the conventional expression “年年有余,” meaning that there is a surplus every year, the explanation supports the surname “余,” although the transcript repeatedly contains “鱼.” The supported revision is “余明洞”: the explanation does not justify changing the remaining characters “明洞.” Conversely, a speaker who explicitly identifies “鱼” through fish or contrasts it with “余” provides evidence for retaining “鱼.” This example separates the transcription from the intended orthography. It also shows why neither literal copying nor unrestricted language-model rewriting is sufficient.

Prior work already uses corrections and conversational information to improve recognition. Audio-exemplar methods retain corrected speech examples for later matching; ontology-based correction stores entities and their relationships from interaction history. Conversational prompting also combines preceding turns with hotword information. Thus, remembering corrections or using dialogue context is not itself the distinction we seek to establish. Our focus is the transition from a potentially corrupted natural-language explanation to an explicit lexical memory that can influence decoding of a later utterance. [Pundak et al., 2022](https://www.isca-archive.org/interspeech_2022/pundak22_interspeech.html); [Li et al., 2026](https://arxiv.org/abs/2606.13464); [Zheng et al., 2026](https://doi.org/10.1016/j.specom.2026.103458).

We introduce **ECHO: Explanations as Context for Hotword Optimization in Speech Recognition**, a framework that connects explanation interpretation to contextual decoding across successive recognition calls. Before a call, the recognizer receives the current session vocabulary. After recognition, a large language model examines the current and recent transcripts, identifies introduced entities, and interprets the spelling evidence associated with them. Candidate hotwords retain a verbatim evidence span and a short explanation of the proposed spelling. Candidates passing format and evidence-span checks are added to session memory, which is available to the next call. These checks preserve provenance but do not certify the inferred spelling. The new memory does not retrospectively alter the call that produced it. This separation allows each utterance to contribute information without requiring a continuously streamed audio input.

ECHO uses the memory to adjust token scores during subsequent ASR decoding. The current implementation applies a stronger bonus when the generated suffix matches a hotword prefix and a weaker, score-gated bonus when starting a hotword. Both the ASR model and the language model retain their pretrained parameters. Here, *optimization* refers to steering decoding with the inferred vocabulary, not to a learned optimization objective or a guarantee of optimal decoding. In particular, a prefix-conditioned bonus cannot ensure that a hotword is reached when its initial token has little support from the recognizer.

The approach exposes three connected research questions. First, can an interpreter recover useful lexical evidence when both a name and its explanatory phrase contain recognition errors? Second, does retaining that evidence improve recognition of later mentions, beyond correcting the original transcript? Third, how can the system limit false corrections and unintended insertions when an explanation is ambiguous or a stored term is irrelevant? The last question is essential: an incorrect memory entry can influence later hypotheses and thereby reinforce its own apparent evidence. Evaluating only the explanation utterance would miss both the intended benefit and this failure mode.

The present work develops three components toward answering these questions:

- An explanation-grounded adaptation setting in which the evidence for a spelling can itself be corrupted, and the effect on later utterances is separated from correction of the explanation itself.
- A modular connection between language-model interpretation, evidence-associated session memory, and prefix-conditioned token-score biasing, without updating model weights.
- An inspectable prototype that exposes the original and biased transcriptions, memory updates, and before/after token probabilities at the same decoding prefix.

These components support a research program on recognition that carries useful explanations forward across interactions. Establishing their effectiveness requires evaluation that separates memory construction from later recognition, includes distractor and contradictory explanations, and measures both target-term accuracy and errors introduced elsewhere in the transcript.

A planned extension treats explanation understanding as action selection: the model may add, revise, or delete lexical memories and propose evidence-supported edits to earlier transcripts. We outline ECHO-Bench to evaluate these decisions together with later recognition. A further direction is to integrate lexical inference into a structured reasoning stage within an end-to-end speech model. These extensions and the benchmark are research plans, rather than completed training or evaluation results.
